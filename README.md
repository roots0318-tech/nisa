# 100歳までの資金計画

老後にほしい生活費から、これから毎月いくら積み立てれば届くかを確率つきで逆算するツールです。

**https://roots0318-tech.github.io/nisa/**

- 新NISAの枠（生涯1,800万円／成長投資枠1,200万円／年間360万円）、課税口座の売却益への課税、
  公的年金、物価の上昇を含めて、100歳までを計算します
- **入力した年齢や金額は、この端末のブラウザの中だけで計算しており、どこにも送信していません。**
  サーバーを持たないので、預かるものがありません
- 銘柄の推奨・スコアリング・順位付け・売買タイミングの判断は行いません

## このリポジトリについて

**公開しているページそのもの**を置いています（ビルド済みのHTML）。
1つのHTMLファイルに計算エンジンまで入っているので、保存すればオフラインでも動きます。

| ファイル | |
|---|---|
| `index.html` | 入口。1問ずつ答えていく画面 |
| `app.html` | 詳細版。すべての条件を1画面で設定する |
| `og.png` | リンクを共有したときのカード画像 |

## 数字の出どころ

- ファンドの正式名称・運用会社・指定指数: 金融庁「つみたて投資枠対象商品届出一覧」
- 信託報酬: 集約サイトから取得した値を収録しています。
  **340本のうち裏を取れているのは12本だけです**（交付目論見書で直接確認 4本、
  投資信託協会の投信総合検索ライブラリーで照合 8本）。
  裏を取った商品は画面のコストの表に出どころと確認日を出しています。それ以外は一次ソース未確認です。
